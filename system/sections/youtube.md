# 🎬 قناة يوتيوب — دوت فور لايف
> **المسؤول:** فلاش + عمر (ثَمبنيلز). الهدف: عمق + اكتشاف + توجيه للموقع.

## ① التجهيز (تشييك)
- [ ] إنشاء/تهيئة القناة + الوصف + الروابط للموقع.
- [ ] هوية بصرية: بانر + قالب ثَمبنيل ثابت (ألوان البراند، محتشم).
- [ ] قوائم تشغيل حسب الأقسام السبعة.

## ③ استراتيجية المحتوى (أنواع تخدم الأقسام)
- **شورتس** (هوك 3ث): نصيحة سريعة من مقال — وصول.
- **فيديو دليل** (5–10د): تحويل أقوى المقالات (الزكاة، التمويل، الحمل...) — عمق + سيو.
- **شرح أداة**: حاسبة من الموقع — توجيه مباشر.
