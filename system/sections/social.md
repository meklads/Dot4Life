# 📱 إدارة السوشيال ميديا
> **المسؤول:** مازن. الهدف: نشر يجلب نقرات للموقع ويبني الجمهور، بهوية محتشمة.

## دور كل منصّة
| المنصّة | الأنسب لها | التكرار |
|---------|-----------|---------|
| إنستغرام | كاروسيل نصائح + ريلز | يومي |
| فيسبوك | مقالات + مجتمع | يومي |
| تويتر/X | Threads + نقاش | 3–5/أسبوع |
| لينكدإن | محتوى مالي/مهني (HumanArchitect لاحقاً) | 2–3/أسبوع |

## الأداة المناسبة (مقارنة + توصية)
| الأداة | المزايا | ملاحظة |
|--------|--------|--------|
| **Metricool** | جدولة متعددة + تحليلات + خطة مجانية جيدة | ✅ مرشّح أولي (يدعم العربي والمنصّات) |
| Buffer | بسيط ونظيف | جدولة أساسية |
| Publer | جدولة + إعادة تدوير | بديل قوي |
| Hootsuite | شامل | أغلى |

## إعادة التدوير (مقال → سوشيال)
كل مقال = كاروسيل (5 نقاط) + ريل (هوك 3 ثوانٍ) + اقتباس + Thread. الـCTA دائماً «الدليل الكامل في الرابط».
