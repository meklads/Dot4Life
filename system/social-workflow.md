## 📝 أنواع المحتوى المطلوبة

### ١. منشورات Instagram (كاروسيل/صورة واحدة)

**العدد:** ١ منشور يومياً على الأقل

**المكونات:**
```
📍 العنوان: (سطر واحد جذاب)
📝 النص: ٣-٥ نقاط (مختصرة ومفيدة)
🔗 الرابط: رابط المقالة (في Bio)
🏷️ الهاشتاقات: ٥-١٠ هاشتاقات مناسبة
🖼️ الصورة: جذابة، عائلية، محترمة
```

**أمثلة:**
```
📍 أم سعودية بنت شركة ناشئة من مطبخها!

من ٣ أطفال وفاتورة مطبخ إلى ١٠٠ ألف ريال 💪
هذي قصة ملهمة لأم سعودية استغلت شغفها بالحلويات
وبدأت مشروعها من البيت

💡 ٣ دروس من قصتها:
١. ابدئي بمطبخك لو عندك شغف
٢. التواصل مع الأمهات = جمهور ذهبي
٣. التدرج هو سر النجاح

🔗 الرابط في البايو

#أم_عاملة #مشاريع_منزلية #ريادة_أعمال_نسائية #السعودية
```

### ٢. Instagram Reels / YouTube Shorts

**مدة:** ١٥-٦٠ ثانية

**سكريبت المقطع:**
```
🎬 مشهد افتتاحي (٣ ثوان) → سؤال أو حقيقة صادمة
🗣️ المحتوى (٢٠-٤٠ ث) → ٣ نصائح سريعة
👋 الخاتمة (٥ ث) → "عشان تعرف أكثر، الرابط في البايو"
```

**مثال:**
```
[0:00] 🎬 "هل تعرف أن عائلة سعودية عاشت بـ ٣٠٠٠ ريال شهرياً؟"
[0:05] "تحدي الادخار القاسي — كيف سووها؟"
[0:10] "النقطة الأولى: أوقفوا المشتريات العاطفية"
[0:20] "النقطة الثانية: طبخوا في البيت بدل الطلبات"
[0:30] "النقطة الثالثة: خطة سداد ديون صارمة"
[0:40] "عشان تقرأ قصتهم كاملة، الرابط بالبايو 🔗"
```

### ٣. منشورات Facebook

**العدد:** ١ منشور يومياً

**الأسلوب:** أطول من Instagram، أكثر تفصيلاً

**مثال:**
```
🌟 قصة ملهمة تستحق القراءة

"أم عربية بنت شركة ناشئة من مطبخها"

نورة، أم لـ ٣ أطفال، كانت تقضي ساعات في المطبخ
تصنع الحلويات لأطفالها. إلى أن قال لها زوجها يوماً:
"ليش ما تحولين هالموهبة لمشروع؟"

🔹 البداية: طلبيات من الأهل والجيران
🔹 التحدي: التوفيق بين البيت والعمل
🔹 النتيجة: اليوم عندها ٣ موظفات وأرباح تتجاوز ١٠٠ ألف سنوياً

الدرس: الشغف + التدرج = نجاح ببطء لكن بثبات

اقرأوا قصتها على موقع دوت فور لايف
الرابط في التعليقات 👇

#قصص_ملهمة #أمهات_عاملات #السعودية
```

### ٤. YouTube فيديو أسبوعي (يوم الجمعة)

**المدة:** ٣-٧ دقائق

**السكريبت:**
```
مقدمة → المشكلة → الحل → خلاصة → دعوة للاشتراك
```

**عنوان الفيديو:** (مُحسّن لليوتيوب)
```
٤ عادات مسائية غيرت حياة عائلة خليجية | دوت فور لايف
كيف توزع راتبك بذكاء؟ دليل الميزانية للعائلة السعودية
العمرة مع الأطفال — ١٠ نصائح قبل ما تسافر
```
