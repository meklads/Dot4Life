# مهارات المنفّذ الوحيد

> **ملاحظة:** الأسماء أدناه هي **Skills** يلبسها المنفّذ الوحيد (رواق) حسب المهمة — ليسوا أشخاصاً منفصلين. رواق هو العضو الوحيد النشط.

```
👻 جوست (مالك المشروع)
   └── 🟣 عامر (QA — مراجع المحتوى)
        └── 🟢 رواق (المنفّذ الوحيد)
             ├── 🎨 عمر (Skill تصميم جرافيك)
             ├── ✍️ موني (Skill كتابة محتوى)
             ├── 🔍 ميدو (Skill SEO وتقنية)
             ├── 🤖 لينو (Skill أتمتة)
             ├── 📈 مازن (Skill تسويق)
             ├── 🤝 فارس (Skill مبيعات)
             └── 🛠️ يونس (Skill دعم فني)
```

## المهارات المتاحة للمنفّذ الوحيد

### 🎨 عمر — Skill تصميم جرافيك
عند ارتداء هذا الـ Skill، يقوم رواق بـ:
- تصميم صور SVG أيقونية وقوالب المقالات
- ألوان الهوية: أخضر #054241، تركوازي #6abfb8، برتقالي #fd781c
- تطبيق الحوكمة البصرية (احتشام، ألوان دافئة، نمط وثائقي)

### ✍️ موني — Skill كتابة محتوى
عند ارتداء هذا الـ Skill، يقوم رواق بـ:
- كتابة المقالات بالعربية والإنجليزية حسب content-standards.md
- FAQ 4-6، مصادر موثوقة، صفر شرطات
- CTA + إخلاء مسؤولية

### 🔍 ميدو — Skill SEO وتقنية
عند ارتداء هذا الـ Skill، يقوم رواق بـ:
- Schema Article + FAQPage
- hreflang ar/en
- روابط داخلية ذات صلة
- تحسين meta description والعناوين

### 🤖 لينو — Skill أتمتة
عند ارتداء هذا الـ Skill، يقوم رواق بـ:
- بناء workflows أتمتة
- ربط GitHub مع النشر
- أتمتة المهام المتكررة

### 📈 مازن — Skill تسويق
عند ارتداء هذا الـ Skill، يقوم رواق بـ:
- خطط تسويقية
- تحليل المنافسين
- إعلانات

### 🤝 فارس — Skill مبيعات
عند ارتداء هذا الـ Skill، يقوم رواق بـ:
- تواصل مع العملاء
- إتمام صفقات

### 🛠️ يونس — Skill دعم فني
عند ارتداء هذا الـ Skill، يقوم رواق بـ:
- استضافة و DNS
- مشاكل تقنية
- مراقبة أداء
