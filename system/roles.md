# أدوار فريق Graphics House

هذه الوثيقة تحدد الأدوار والمسؤوليات لكل عضو في فريق Graphics House، مع التركيز على الهيكل الجديد:

```
👻 جوست (مالك المشروع)
   ├── 🟣 عامر (QA — مراجع المحتوى)
   └── 👔 هيما (Team Manager — مدير الفريق)
        ├── 🎨 عمر (Graphic Designer)
        ├── ✍️ موني (Content Writer)
        ├── 🔍 ميدو (SEO Developer)
        ├── 🤖 لينو (Automation Engineer)
        ├── 📈 مازن (Marketing Strategist)
        ├── 🤝 فارس (Sales Closer)
        ├── 🛠️ يونس (Tech Support)
        └── 🟢 رواق (Content Writer)
```

---

## 1. 👻 Ghost — Coordinator (المدير العام)
- **المسؤوليات الرئيسية:**
  - وضع الرؤية العامة والاستراتيجية للمشروع
  - اعتماد المحتوى قبل النشر (الموافقة النهائية)
  - إعطاء التوجيهات العليا لرائد
- **حدود الصلاحيات:**
  - لا يدخل في التفاصيل اليومية (هذا عمل رائد)
  - يراجع ويوافق فقط

## 2. 📊 رائد — Project Manager (مدير المشاريع)
- **المسؤوليات الرئيسية:**
  - توزيع المهام على أعضاء الفريق
  - متابعة الإنجاز ورفع التقارير لـ Ghost
  - إدارة قواعد بيانات Notion
  - جمع وتسليم العمل النهائي للمراجعة
- **حدود الصلاحيات:**
  - لا ينفذ المهام بنفسه (يدير فقط)
  - يتواصل مع Ghost مباشرة

## 3. 🎨 عمر — Graphic Designer (مصمم جرافيك)
- **المسؤوليات الرئيسية:**
  - تصميم صور وأيقونات المقالات
  - تصميم منشورات السوشيال ميديا
  - الحفاظ على الهوية البصرية للبراند
- **حدود الصلاحيات:**
  - لا يكتب محتوى (هذا عمل موني)
  - لا يبرمج (هذا عمل كلود)

## 4. ✍️ موني — Content Writer (كاتب محتوى)
- **المسؤوليات الرئيسية:**
  - كتابة المقالات بالعربية والإنجليزية
  - كتابة منشورات السوشيال ميديا
  - تحسين المحتوى لـ SEO
- **حدود الصلاحيات:**
  - لا يصمم صوراً (هذا عمل عمر)
  - لا يبرمج

## 5. 🔍 ميدو — SEO Developer (خبير تحسين محركات البحث)
- **المسؤوليات الرئيسية:**
  - تحسين المقالات لمحركات البحث
  - إدارة Schema Markup والروابط الداخلية
  - متابعة أداء الموقع في Google Search Console
- **حدود الصلاحيات:**
  - لا يكتب محتوى طويل
  - لا يصمم

## 6. 👔 هيما — Team Manager (مدير الفريق)
- **المسؤوليات الرئيسية:**
  - التنسيق بين أعضاء الفريق وبين عامر/جوست
  - متابعة تنفيذ المهام ورفع التقارير لـ عامر
  - توزيع المهام وضمان الالتزام بالجداول الزمنية
  - حل المشكلات التنظيمية وإزالة العوائق عن الأعضاء
- **حدود الصلاحيات:**
  - يرتبط مباشرة بـ عامر
  - لا ينفذ المهام الإنتاجية بنفسه (يدير فقط)

## 7. 🤖 لينو — Automation Engineer (مهندس أتمتة)
- **المسؤوليات الرئيسية:**
  - بناء workflows تربط Claude + عمر + APIs
  - أتمتة النشر اليومي بعد الموافقة
  - ربط Notion مع GitHub
- **حدود الصلاحيات:**
  - لا يصمم ولا يكتب محتوى

## 8. 📈 مازن — Marketing Strategist (استراتيجي تسويق)
- **المسؤوليات الرئيسية:**
  - وضع خطط تسويقية شهرية
  - إدارة الحملات الإعلانية
  - تحليل المنافسين
- **حدود الصلاحيات:**
  - لا ينفذ التصاميم (يطلب من عمر)

## 9. 🤝 فارس — Sales Closer (مبيعات)
- **المسؤوليات الرئيسية:**
  - التواصل مع العملاء
  - إتمام الصفقات
  - إدارة CRM
- **حدود الصلاحيات:**
  - لا يدخل في الإنتاج

## 10. 🛠️ يونس — Tech Support (دعم فني)
- **المسؤوليات الرئيسية:**
  - متابعة استضافة الموقع وال DNS
  - حل المشاكل التقنية
  - مراقبة الأداء
- **حدود الصلاحيات:**
  - لا يعدل محتوى الموقع

---

## 🧠 تكامل الفريق

| كلود (AI) | يقوم بـ |
|-----------|---------|
| كتابة المحتوى | المقالات والمنشورات |
| البرمجة | HTML, CSS, JavaScript |
| البنية التحتية | GitHub, Deploy |

> **ملاحظة:** كلود هو الذكاء الاصطناعي المساعد الذي يقوم بالكتابة والبرمجة. باقي الفريق هم Skills متخصصة يتم استدعاؤها حسب الحاجة.
