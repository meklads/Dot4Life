# مهارات المنفّذ (Hema) — النموذج الخماسي المقوّى · 2026-06-24

> **القانون الحاكم الكامل لهيما: [`operating-system/HEMA-CHARTER.md`](../operating-system/HEMA-CHARTER.md)** — قواعد السلوك (تمنع اللف والدوران) + خريطة الاستدعاء + معايير 2026 لكل سكيل. هذا الملف ملخّص؛ الميثاق هو المرجع.
>
> **كل الخمسة هم Hema** — نفس المنفّذ يلبس **سكيلاً مختلفاً** حسب المهمة (ليسوا أشخاصاً). كل سكيل **مربوط بقانون حاكم** ومسقوف بمعيار جودة عالٍ. **عامر** بوّابة الجودة الوحيدة فوق الجميع.

```
👻 جوست (مالك المشروع · رؤية وقرار)
   └── 🛡️ عامر (بوّابة الجودة الوحيدة — لا LIVE إلا بإجازته)
        └── 🟢 Hema (المنفّذ — يلبس 5 سكيلات)
             ├── ✍️ سكيل الكتابة   (Writing Skill)   ← إنتاج
             ├── 🔍 سكيل التحليل   (Analysis Skill)  ← إنتاج
             ├── 🎨 سكيل التصميم   (Design Skill)    ← إنتاج
             ├── 💻 سكيل البرمجة   (Dev Skill)       ← إنتاج
             └── 📣 سكيل النمو      (Growth Skill)    ← بعد النشر
```

**خط الإنتاج:** سكيل الكتابة → سكيل التحليل → سكيل التصميم → سكيل البرمجة → **بوابة عامر** → LIVE.
**خط النمو (موازٍ، بعد LIVE):** سكيل النمو يوزّع المنشور ويبني الجمهور.

## السكيلات الأربعة (كلٌّ مقوّى لأقصى درجة)

### ✍️ سكيل الكتابة — Writing Skill
**المهارة:** كتابة المحتوى والتحرير. · **القانون الحاكم:** `operating-system/WRITING-LAW.md` + `content-standards.md`.
- مقالات **عميقة دسمة آدمية 1600–2400 كلمة** (≥1300 صارم) بلا حشو.
- **خطّاف أول سطر + قوس عاطفي + خاتمة تُحرّك** + اجتياز **اختبار المشاركة**.
- **1–2 قصة/مشهد حيّ مدموج** (تمثيلي، بلا اختلاق منسوب لحقيقي).
- **3–5 مصادر https محقّقة بالاسم** · لا رقم بلا مصدر · لا اقتباس مختلَق.
- نسختان (عربي/إنجليزي) بنفس العمق والقصص.
- **معيار القبول:** ≥4/5 في كل بُعد (العمق · الأسلوب · القصة · المراجع · التأثير).

### 🔍 سكيل التحليل — Analysis Skill
**المهارة:** تحليل البيانات وتحسين محركات البحث (SEO). · **المرجع:** `content-standards.md` (§6) + أدوات التحليل.
- **بحث كلمات مفتاحية** طويلة الذيل منخفضة المنافسة (نية بحث واضحة) قبل الكتابة.
- **Schema سليم:** `Article` + `FAQPage` صحيحا JSON · `hreflang` ar/en · canonical.
- **Title ≤60 · Meta ≤155 جذّاب · 3+ روابط داخلية وصفية** (أداة ↔ مقال).
- تحليل أداء (الزيارات/الكلمات الرابحة) واقتراح تحسينات وفجوات محتوى.
- **معيار القبول:** كل مقال يستهدف كلمة حقيقية يبحثها الخليجي + بنية SEO مكتملة محقّقة آلياً.

### 🎨 سكيل التصميم — Design Skill
**المهارة:** تصميم واجهات وتجربة المستخدم (UI/UX). · **القانون الحاكم:** `operating-system/VISUAL-DIRECTION.md` + `article-template-spec.md`.
- **الصور الرئيسية:** برومبتات عالية المعايير (احتشام كامل · هوية تيل/كريمي/ذهبي · تنويع · نسبة أشخاص ~1:5 · حياة جميلة · حيوانات مرحّب بها). *(التوليد الفعلي عبر Higgsfield = عامر؛ هذا السكيل يجهّز البرومبت والتصميم.)*
- **قالب المقال الكامل:** هيدر + بانر بعرض 1100px + سايدبار + فوتر · تجربة قراءة مريحة.
- أيقونات SVG على الهوية · تباين ووضوح · **متجاوب جوال** أولاً.
- **معيار القبول:** يمرّ بوابة الاحتشام والهوية + التمبليت كامل + تجربة جوال ممتازة.

### 💻 سكيل البرمجة — Dev Skill
**المهارة:** برمجة وتطوير واجهات الويب (Front-End). · **المرجع:** `article-template-spec.md` + سكربتات البناء.
- بناء صفحات HTML/CSS/JS نظيفة من المسودة المعتمدة عبر `build-from-approved-draft.py`.
- حقن Schema · ربط الصورة الصحيحة · روابط داخلية · أداء (WebP، تحميل كسول) · **متجاوب**.
- نشر ودفع تلقائي (autopilot) + حذف مكرّرات `assets/queue/`.
- **معيار القبول:** صفحة سليمة بنيوياً تجتاز `--audit` + بوابة عامر البصرية/التقنية قبل LIVE.

### 📣 سكيل النمو — Growth Skill (يعمل على المنشور، خارج خط الإنتاج)
**المهارة:** النشر على السوشيال ميديا + التوزيع + بناء الجمهور. · **يبدأ بعد LIVE.**
- **التوزيع:** نشر المقال على تويتر/X · إنستغرام · واتساب · نشرة بريدية.
- **إعادة التدوير:** المقال الواحد → ثريد · ريل قصير · بطاقة إنفوجرافيك · سؤال نقاش.
- **عناقيد المحتوى:** ربط المقالات ببعضها لتقوية ترتيب الموقع كله في جوجل.
- **متابعة ومضاعفة:** ما جاب زيارات → اكتب أمثاله؛ ما فشل → اتركه.
- **بناء الجمهور:** تحويل القارئ العابر إلى مشترك يعود (بريد/متابعة).
- **معيار القبول:** كل مقال LIVE له خطة توزيع + إعادة تدوير واحدة على الأقل، والاحتشام والهوية تنطبق على أصول السوشيال أيضاً.
> **الحالة:** مُعرَّف وجاهز. **يُفعَّل بأمر جوست** (الأنسب بعد تجميع مخزون ٤٠–٥٠ مقالاً قوياً).

## 🛡️ بوّابة عامر (فوق السكيلات الخمسة)
لا شيء يطلع LIVE إلا بعد إجازة عامر — **نصاً (Writing) وبنيةً (Analysis) وصورةً/قالباً (Design) وصفحةً (Dev).** وأصول النشر (Growth) تمرّ ببوابة الاحتشام والهوية أيضاً. الأتمتة تنفّذ، وعامر يجيز.

## 🧠 ملاحظة تطوير (اقتراح عامر)
- **كل سكيل مربوط بقانونه** (لا اجتهاد بلا معيار) — هذا يرفع الثقل لأقصى درجة.
- **الترتيب ثابت** يمنع الفوضى: لا تصميم قبل كتابة معتمدة، ولا بناء قبل تصميم معتمد.
- **مقياس 4/5** لكل سكيل يجعل «يمرّ» غير كافٍ؛ الهدف «ممتاز».
