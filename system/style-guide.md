# DotForLife Style Guide (Base Structure)

## 1. Writing Tone
- Friendly, clear, and helpful.
- Simple Arabic suitable for Gulf families.
- Avoid overly complex or academic language.

## 2. Article Structure
- Title
- Short introduction
- Main sections with clear headings
- Bullet points when needed
- Summary or key takeaways at the end

## 3. SEO Requirements
- Meta title (60 characters max)
- Meta description (150–160 characters)
- 5–10 keywords
- Internal links to relevant DotForLife sections
- External links only when necessary

## 4. Formatting Rules
- Short paragraphs
- Clear spacing
- Use headings (H2, H3)
- Avoid long blocks of text

## 5. Image Guidelines
- Use relevant, high-quality images
- Include alt text
- Follow DotForLife visual identity

## 6. Content Categories
- Blog
- Featured Stories
- Comparisons
- Peace Capsules
- Pregnancy
- Travel
- Real Estate
- Islamic Content

This is only the base structure. Detailed rules will be added later.
