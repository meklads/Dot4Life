## دورك (بسيط، مرة واحدة كدفعة)
1. افتح ملف البرومبتات: `image-prompts-batch-01.md` (جنب الملف ده).
2. خُد كل برومبت، الزقه في Ideogram، ولّد الصورة.
3. نزّل الصورة واحفظها هنا **بنفس رقم البرومبت واسمه** — مثلاً:
   - البرومبت رقم 1 (savings) ← احفظها باسم `01-savings.png`
   - البرومبت رقم 2 (health) ← `02-health.png`
   - وهكذا…
4. خلّصت الدفعة؟ قوللي «الصور جاهزة».

- المرفوضة → أقوللك السبب والبرومبت المعدّل تعيد توليدها.
- بعدها الأوتوبايلوت يحقن الصور في المقالات تلقائياً.
