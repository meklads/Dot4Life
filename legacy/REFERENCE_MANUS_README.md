# DOTFORLIFE: Life, at ease. 🌍✨

> **"Your trusted daily life platform for families. One calm place for life's everyday decisions."**

---

## 📖 Overview
**DOTFORLIFE** is a world-class, bilingual (Arabic/English) platform designed to simplify family life. It provides a comprehensive suite of tools, guides, and insights across five core pillars: **Health, Finance, Real Estate, Travel, and Islamic Life.**

The platform is built with a "Luminous Utility" philosophy—combining aesthetic beauty with practical, high-performance functionality.

---

## 🏗 Project Structure

The project is organized into a highly structured and scalable architecture to ensure clarity for developers, designers, and content creators.

### 1. 🌐 `public_html/` (The Core Platform)
This is the production-ready directory containing all client-side assets.
*   **`index.html`**: The main entry point featuring the "Capsule Engine" and daily inspiration.
*   **`styles/`**: Modular CSS architecture (Global, Home, and Page-specific styles).
*   **`scripts/`**: Core logic, including `global.js` for theme and language management.
*   **`tools/`**: A library of 20+ interactive calculators (Mortgage, Zakat, BMI, etc.).
*   **`guides/`**: Deep-dive editorial content and family resources.
*   **`blog/`**: Insights and updates tailored for the GCC and Middle East.
*   **`cities/`**: Specialized content for major hubs (Riyadh, Dubai, Jeddah, etc.).

### 2. ⚙️ `capsule-engine/` (Dynamic Content)
The backend logic responsible for delivering daily "Peace Capsules"—automated, context-aware content snippets that refresh every 24 hours.

### 3. 📝 `content/` & `system/` (Workflow & Data)
*   **`content/`**: Markdown-based data source for blog posts, featured stories, and tools.
*   **`system/`**: Internal project management files, including:
    *   `workflow.md`: Content production pipeline.
    *   `style-guide.md`: Visual and editorial standards.
    *   `roles.md`: Team responsibilities and permissions.

### 4. 📂 `_docs/` (Strategic Intelligence)
Contains high-level strategic documents that guide the project's growth.
*   `DOTFORLIFE_Strategy_Playbook.docx`: The global expansion roadmap.
*   `dotforlife-design-philosophy.md`: The "Luminous Utility" design manual.
*   `Team_Philosophy_and_Skills_Guide.md`: Detailed breakdown of the virtual team's capabilities.
*   `Dockerfile` & `VERSION.json`: Deployment and versioning configurations.

### 5. 🤖 `_manus_management/` (AI Operations)
The dedicated command center for Manus AI, containing project dashboards, team logs, and execution plans.

## 🚀 Key Features
*   **Bilingual First:** Seamless RTL/LTR switching with localized content.
*   **Performance Driven:** Optimized for speed with DNS prefetching and critical CSS.
*   **Privacy Centric:** Built with a "Privacy by Design" approach for family data.
*   **Modular Tools:** Easily extensible calculator and guide systems.
