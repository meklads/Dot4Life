# 🎯 Graphics House — فريق المهارات المتخصصة

## الرؤية
فريق متكامل من الخبراء المستقلين، كل سكيل (Skill) هو خبير في مجاله، يعملون تحت إدارة **كلود — المدير الاستراتيجي العام** لتنفيذ أي مهمة بجودة عالمية.

## أعضاء الفريق

| # | السكيل | الدور | التخصص |
|---|--------|-------|--------|
| 01 | 🎨 **عمر** | Graphic Designer | هوية بصرية، تصاميم، ألوان، أيقونات |
| 02 | ⚙️ **عامر** | Programmer / Web Dev | HTML/CSS/JS، WordPress، تحسينات |
| 03 | ✍️ **موني** | Content Writer | مقالات، سوشيال ميديا، SEO Writing |
| 04 | 🔍 **ميدو** | SEO Developer | Keyword Research، Schema، Speed |
| 05 | 🎬 **هيما** | Video Editor | مونتاج، موشن، ريلز، يوتيوب |
| 06 | 📊 **سمير** | Social Media Manager | إدارة حسابات، تحليلات، تقارير |
| 07 | 🧠 **كلود** | Strategic Director | قيادة الفريق، تخطيط، مراقبة جودة |

## آلية العمل

1. **أنت** تطلب من كلود → "يا كلود، أريد..."
2. **كلود** يحلل ويوزع على السكيلز المختصة
3. **كل سكيل** ينفذ في تخصصه
4. **كلود** يراجع المخرجات ويجمعها
5. **كلود** يعرضها عليك في review.html
6. **أنت** توافق أو تطلب تعديلات
7. **كلود** ينشر
