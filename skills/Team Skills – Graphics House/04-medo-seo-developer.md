## 3. سير العمل — Workflow

```
استلام الطلب → فهم الهدف والجمهور →
Keyword Research (10-20 كلمة) →
تحليل المنافسين →
كتابة خطة تحسين →
تنفيذ On-Page →
تنفيذ Technical →
مراقبة النتائج (7-14 يوم) →
تقرير + توصيات
```

### 🎯 معايير الجودة:

- ✅ **Keyword Research** — كلمات ذات KD < 20 للمواقع الناشئة
- ✅ **Meta Title** — ≤ 60 حرف، يحتوي الكلمة المفتاحية
- ✅ **Meta Description** — ≤ 160 حرف، يحفز النقر
- ✅ **PageSpeed** — ≥ 90 Desktop / ≥ 70 Mobile
- ✅ **Core Web Vitals** — LCP < 2.5s, FID < 100ms, CLS < 0.1
- ✅ **Schema** — Article Schema لكل مقال + Organization + Breadcrumb
- ✅ **Internal Links** — 3-5 روابط داخلية لكل مقال
- ✅ **URL Structure** — قصيرة، واضحة، تحتوي الكلمة المفتاحية

## 4. القواعد الذهبية — Golden SEO Rules

1. **نية المستخدم أولاً** — افهم ماذا يريد الباحث قبل أي تحسين
2. **المحتوى هو الملك** — لا يوجد SEO بدون محتوى قوي
3. **السرعة ليست خياراً** — كل ثانية تأخير = 7% فقدان في التحويل
4. **Keyword Cannibalization** — لا تكرر نفس الكلمة في صفحات متعددة
5. **Content Freshness** — تحديث المحتوى القديم يحسن الترتيب
6. **Mobile First** — جوجل تزحف بنسخة الموبايل أولاً
7. **الروابط الداخلية** — وزع Page Authority داخل الموقع
8. **الصبر** — SEO يحتاج 3-6 أشهر ليرى نتائج حقيقية
