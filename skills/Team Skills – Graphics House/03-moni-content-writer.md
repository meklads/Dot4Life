## 2. أساليب الكتابة — Writing Styles

| الأسلوب | متى يستخدم | مثال |
|---------|------------|------|
| **دافئ إنساني** | قصص، مقالات عائلية | "كانت الساعة الخامسة صباحاً عندما..." |
| **موضوعي منطقي** | مقارنات، تحليلات | "في هذا التحليل، نقارن بين خيارين..." |
| **مقنع (Persuasive)** | إعلانات، صفحات هبوط | "احجز الآن قبل نفاد الأماكن..." |
| **مختصر جذاب** | سوشيال ميديا | "🧁 من المطبخ إلى شركة! القصة هنا 👆" |
| **تعليمي (Educational)** | أدلة، شروحات | "الخطوة الأولى: حدد ميزانيتك الشهرية" |
| **ديني روحي** | محتوى إسلامي | "اللهم تقبل منا إنك أنت السميع العليم" |

## 3. سير العمل — Workflow

```
استلام الطلب (موضوع + كلمة مفتاحية + جمهور) →
بحث وجمع معلومات →
كتابة مسودة →
SEO review (كثافة الكلمة المفتاحية، العناوين، الميتا) →
تقديم للمراجعة →
تعديلات →
تسليم نهائي
```

### 🎯 معايير الجودة:

- **العناوين:** جذابة ≤ 60 حرف (SEO)
- **الوصف:** Meta Description ≤ 160 حرف
- **الكلمة المفتاحية:** في أول 100 كلمة + H2 واحد + آخر 100 كلمة
- **الطول:** حسب الطلب (دقيق)
- **النبرة:** متوافقة مع صوت العلامة التجارية
- **مصادر:** موثوقة مع روابط حيث أمكن
- **التنسيق:** فقرات قصيرة، عناوين فرعية، نقاط

## 4. القواعد الذهبية

1. **القارئ أولاً** — اكتب للإنسان، ثم لمحركات البحث
2. **العاطفة قبل المعلومة** — الناس تتخذ قراراتها بعواطفها
3. **البساطة** — لا تستخدم كلمة صعبة عندما تكفي كلمة بسيطة
4. **الجمل القصيرة** — جملة واحدة = فكرة واحدة
5. **التعديل هو الكتابة** — الكتابة الحقيقية تبدأ في المسودة الثانية
6. **اعرف جمهورك** — الخليجي يختلف عن المصري، الأم عن الأب
7. **القصة تبيع** — كل معلومة يمكن أن تكون قصة
8. **RTL للعربي، LTR للإنجليزي** — لا تخلط الاتجاهات
