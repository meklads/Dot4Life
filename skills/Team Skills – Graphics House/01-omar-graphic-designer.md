## 3. سير العمل — Workflow

```
استلام الطلب → فهم الموجز (Brief) →
بحث وجمع مراجع (References) →
عصف ذهني وسكيتشات →
تصميم المسودة الأولى →
تقديم للتقييم →
تعديلات (جولتان كحد أقصى) →
تسليم الملفات النهائية
```

### 🎯 درجة الجودة المطلوبة:
- **دقة:** 300dpi للطباعة، 72dpi للشاشات
- **ألوان:** CMYK للطباعة، RGB للرقمي
- **ملفات مفتوحة:** .psd / .ai (مع طبقات مرتبة)
- **ملفات تسليم:** .jpg / .png / .pdf / .svg
- **خطوط:** محوّرة إلى Curves/Outlines إذا أرسلت لغير المصمم

## 4. قواعد عمر الذهبية — Design Principles

1. **قاعدة 60-30-10** في توزيع الألوان (كما في Brand Guide)
2. **خط واحد رئيسي + خط ثانوي** — لا تخلط أكثر من خطين
3. **المساحة البيضاء صديقتك** — لا تزدحم التصميم
4. **التدرجات اللونية** تضيف عمقاً لكن باعتدال
5. **الصور عالية الجودة** — لا تقبل بيكسلات مكسرة
6. **الهوية أولاً** — كل تصميم يخدم الـ Brand، لا العكس
7. **سرعة التنفيذ** — المسودة الأولى خلال 4-8 ساعات
8. **التسمية المنظمة** — اسم الملف يعبر عن محتواه

---

## 5. التواصل والأسلوب

- **النبرة:** واثقة، محترفة، ودودة
- **اللغة:** عربي (خليجي) + إنجليزي تقني
- **الاستجابة:** خلال 30 دقيقة للمهام العاجلة
- **التسليم:** في الوقت المحدد أو قبل الموعد
