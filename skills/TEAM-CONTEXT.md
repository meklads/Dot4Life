# 🧭 TEAM-CONTEXT — نظام تشغيل DotForLife (النسخة الخفيفة)

> المرجع المشترك بين **عامر** (Cowork) و **رواق**. اقرأني أولاً قبل أي عمل.
> الفلسفة: **Production-first** — ابنِ الجرّ أولاً، ووسّع النظام لاحقاً حسب الحاجة الحقيقية.

---

## 1. المبدأ الحاكم
- الـ**Skills = قدرات تنفيذية (Doers)**، وليست مدراء.
- **Ghost (صاحب العمل) هو المنسّق والقرار** — لا CEO، لا مدراء وسطى، لا سلاسل موافقات.
- القابلية للتوسع تأتي من **نواة خفيفة قابلة للامتداد** (أضف ملفاً، لا تُعد الهيكلة) — لا من بناء طبقات فارغة مبكراً.
- ممنوع إعادة إضافة: CEO / Analysts / Product Manager / سلاسل قرار / KPIs متعددة المستويات.

## 2. تقسيم العمل (مَن يفعل ماذا)

| | **عامر** (Cowork) — أغلى، أعلى مهارة | **رواق** (Claude Ship) — أرخص، مستمر |
|---|---|---|
| الدور | المعماري + المراجعة + الشغل عالي الرافعة | التنفيذ بالحجم اليومي |
| يفعل | بناء/تطوير الـskills، التصميم والكود المعقّد، الاستراتيجية الشهرية، QA لمخرجات Ship | كتابة المقالات، تطبيق SEO، السوشيال، نصوص الإعلانات، سكربتات الفيديو |
| القاعدة | **"ابنِ مرة، يُستخدم ألف مرة"** | **"شغّل الـskill يومياً"** |

> التنسيق بيننا **عبر هذه الملفات** (مصدر حقيقة واحد)، لسنا في جلسة حيّة مشتركة.

## 3. الفريق (Skills الفعّالة)

| Skill | الوظيفة | يُستخدم في |
|-------|---------|-----------|
| `content-writer` | كتابة مقالات الأقسام الستة (عربي/إنجليزي) | DotForLife |
| `seo` | بحث كلمات، on-page، schema، فهرسة، GSC | DotForLife |
| `designer` | صور المقالات + ثَمبنيلز يوتيوب + تصاميم سوشيال | الكل |
| `social-media` | تقويم نشر، كابشن، إعادة تدوير المحتوى | السوشيال |
| `video-youtube` | سكربت + بنية مونتاج + SEO فيديو | يوتيوب |
| `ads-manager` | حملات Meta/Google، استهداف، ميزانية، ROAS | الإعلانات |

**مركون (dormant، لا يُحذف):** أدوار الإدارة القديمة (رائد/يوسف/نادر/جاد) + المبيعات (فارس) لـ Graphics House حتى أول Lead.

## 6. كيف تُستخدم الـSkills
- في Cowork (عامر): تُستدعى تلقائياً حسب الوصف، أو يدوياً بالاسم.
- لـ رواق: انسخ مجلد `skills/` إلى مجلد الـskills في ريبو DotForLife (مثل `.claude/skills/`) ليحمّلها.
- الـSkills بصيغة `SKILL.md` القياسية **قابلة للنقل** بين الأداتين — مصدر واحد، استخدام مشترك.

## 7. قاعدة التوسع (رخيصة)
عند نمو مشروع/قناة جديدة: **أضف skill جديدة أو ملف dashboard جديد** — لا تُعد بناء النظام. النواة مصمّمة للامتداد.
