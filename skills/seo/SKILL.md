# SEO — DotForLife

## Mission
جعل صفحات DotForLife تظهر في نتائج البحث وتُفهرس بأسرع وقت، بأعلى معايير تقنية.

## متى تُستخدم
قبل نشر أي مقالة/أداة، وفي أي تدقيق دوري، وعند متابعة الفهرسة/الترافيك.

## سير العمل
1. **بحث الكلمات:** كلمة رئيسية واحدة (نية واضحة) + 3–5 ثانوية/long-tail خليجية. تحقّق من المنافسة والنية الحقيقية.
2. **On-Page:**
   - Title ≤ 60 حرف يحوي الكلمة الرئيسية + قيمة.
   - Meta description ≤ 155 حرف، جذّابة، تحوي الكلمة.
   - H1 واحد، H2/H3 منطقية تحوي ثانويات.
   - الكلمة الرئيسية في أول 100 كلمة + alt للصور.
3. **Schema (JSON-LD):** `Article` دائماً + `FAQPage` إن وجدت أسئلة + `BreadcrumbList`. تحقّق أنها صحيحة.
4. **الربط الداخلي:** كل صفحة تربط 2–3 صفحات ذات صلة (أداة ↔ مقالة)، ونص الرابط وصفي.
5. **التقني:** canonical صحيح (للصفحة نفسها)، hreflang (ar/en)، الصفحة في `sitemap.xml`، الصور WebP، lazy-load.
6. **الفهرسة:** بعد النشر، اطلب الفهرسة في Google Search Console وتابع التغطية.

## القاعدة الخليجية
- استهدف كلمات بالعربية الخليجية + الإنجليزية حسب القسم.
- راقب نية البحث (معلوماتية مقابل أداة) وطابق نوع الصفحة معها.

## المقاييس التي تتابعها (4 فقط — تُغذّي لوحة الجرّ)
صفحات مفهرسة · نقرات عضوية/شهر (GSC) · كلمات في Top 10 · PageSpeed.

## Definition of Done ✅
- [ ] كلمة رئيسية + 3–5 ثانوية محدّدة
- [ ] Title/Meta/H-tags محسّنة، الكلمة في أول 100 كلمة
- [ ] Schema صحيح (Article + FAQ إن وجد)
- [ ] 2–3 روابط داخلية وصفية
- [ ] canonical + hreflang + في sitemap + صور WebP
- [ ] طلب فهرسة في GSC بعد النشر

## ⚠️ تحذير
لا over-optimization (حشو كلمات، روابط مفرطة) — يسبّب عقوبات. الطبيعية أولاً.
