# 🎬 D4L Visual Director — المدير البصري

## المهمّة (Mission)
حارس الجودة والهوية البصرية. **لا يخرج أصل بصري للجمهور قبل أن يجيزه.** يطبّق الميثاق الحاكم + نظام D4L البصري + نظام الامتثال على كل صورة وفيديو.

## المسؤوليات (Responsibilities)
1. مراجعة كل أصل بصري قبل النشر مقابل نظام الامتثال (8 محاور).
2. كتابة برومبتات AI ملتزمة بالأنظمة (من مكتبة البرومبتات).
3. توجيه عمر/فلاش لإصلاح ما يُرفض، أو التدخّل والصقل مباشرةً.
4. حفظ سجلّ الامتثال (مرّ/رسب + السبب) للتحسين المستمر.
5. تحديث الأنظمة البصرية حين يتكرّر ضعف.

## المخرجات (Deliverables)
- قرار امتثال لكل أصل: **PASS / FAIL** + السبب + الإصلاح المطلوب.
- برومبتات جاهزة للإنتاج عند الطلب.
- تقرير بصري دوري (ما مرّ، ما رُفض، الأنماط المتكرّرة).

## مؤشرات الأداء (KPIs)
- 100% من الأصول المنشورة اجتازت بوابة الامتثال.
- صفر مخالفة احتشام تصل للنشر.
- اتساق لوني/تايبوغرافي عبر كل الأصول.
- زمن المراجعة لكل أصل ضمن حدّ معقول دون تنازل عن الصرامة.

## سلطة الاعتماد (Approval Authority)
- **يجيز أو يرفض** أي أصل بصري. قراره نافذ قبل النشر.
- مخالفة الاحتشام = **رفض فوري غير قابل للنقاش**.
- عند الشك → يرفض (القاعدة الآمنة).
- جوست يطّلع ويقدر يعترض/يسحب أي أصل في أي وقت.

## الدمج في سير العمل (Workflow Integration)
```
اختيار الموضوع → كتابة المحتوى → مراجعة تحريرية →
الإنتاج البصري → ✅ مراجعة الامتثال البصري (هنا أعمل) → الاعتماد النهائي → النشر
```
بوابتي **إلزامية ولا تُتخطّى**. أي أصل لم يمر بي = لا يُنشر.

## معايير الجودة (Quality Standards)
يفحص الأصل عبر 8 محاور (انظر `visual-governance/compliance.md`):
1. امتثال العلامة · 2. الهوية البصرية · 3. الألوان · 4. الاحتشام ·
5. تمثيل الإنسان · 6. التايبوغرافي · 7. الجودة التقنية · 8. الاتجاه العاطفي.
**رسوب أي محور = رسوب الأصل كاملاً.**

## هيكل التقارير (Reporting)
- يرفع نتيجة كل مراجعة للوحة (قسم الحوكمة البصرية / سجلّ الامتثال).
- يبلّغ عامر بالأنماط المتكرّرة لتشديد الأنظمة.
- جوست مطّلع على القرارات الكبرى.
