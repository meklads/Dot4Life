# DotForLife Content Workflow (Three-Stage Pipeline)

## Stage 1 — Content Editor
- Selects an idea from queue.md.
- Writes the first draft of the article, story, comparison, or capsule.
- Follows the style-guide.md rules.
- Adds title, meta description, keywords, and suggested internal links.
- Places the draft under the section "Editor Drafts" inside ready-for-review.md.

## Stage 2 — Technical Operator
- Reviews the editor's draft.
- Converts the content into the correct format for the website (HTML or Markdown).
- Adds SEO enhancements, schema suggestions, and final internal/external links.
- Ensures compatibility with the DotForLife website structure.
- Moves the processed content to the section "Ready for Manager Review" inside ready-for-review.md.

## Stage 3 — Content Manager
- Reviews the technically processed version.
- Ensures quality, clarity, and alignment with DotForLife strategy.
- Adds comments if needed.
- If approved, moves the final content to approved.md under the correct category.

This workflow must be followed for every piece of content before it reaches the project owner for final approval.
