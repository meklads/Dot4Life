# لوحة تحكم مشروع Dot4Life

مرحباً بك في لوحة تحكم مشروع Dot4Life! هذه الوثيقة هي نقطة البداية لمتابعة تقدم المشروع، المهام الحالية، وكيفية استخدام فريق العمل للملفات المنظمة في مجلد `system`.

## 1. حالة المشروع الحالية

*   **النسخة المعتمدة:** تم تحديث المستودع بنجاح بآخر نسخة من الموقع من جهازك المحلي.
*   **هيكل الفريق:** تم تحديد وتوثيق أدوار ومهارات فريق العمل الافتراضي في `_manus_management/Professional_Skills_Directory.md`.
*   **التنظيم:** تم نقل جميع ملفات الإدارة إلى مجلد `_manus_management` لضمان نظافة المجلد الرئيسي.
*   **الخطوة التالية:** البدء في تنفيذ المهام المحددة في خطة التنفيذ.

## 2. سير عمل المحتوى (Content Workflow)

سنتبع سير عمل المحتوى الموضح في `system/workflow.md` لإدارة جميع أنواع المحتوى (مقالات، قصص، مقارنات، كبسولات). إليك ملخص سريع:

### أ. المرحلة 1: محرر المحتوى (Content Editor - ريم/خالد)
*   يختار فكرة من `system/ideas.md`.
*   يكتب المسودة الأولى ويتبع `system/style-guide.md`.
*   يضيف العنوان، الوصف التعريفي (Meta Description)، الكلمات المفتاحية، والروابط الداخلية المقترحة.
*   يضع المسودة في قسم "Editor Drafts" داخل `system/ready-for-review.md`.

### ب. المرحلة 2: المشغل التقني (Technical Operator - فارس/ليلى)
*   يراجع مسودة المحرر.
*   يحول المحتوى إلى التنسيق الصحيح للموقع (HTML أو Markdown).
*   يضيف تحسينات SEO، اقتراحات Schema، والروابط النهائية.
*   ينقل المحتوى المعالج إلى قسم "Ready for Manager Review" داخل `system/ready-for-review.md`.

### ج. المرحلة 3: مدير المحتوى (Content Manager - مانوس/كلود)
*   يراجع النسخة المعالجة تقنياً.
*   يضمن الجودة، الوضوح، والتوافق مع استراتيجية DotForLife.
*   يضيف تعليقات إذا لزم الأمر.
*   إذا تمت الموافقة، ينقل المحتوى النهائي إلى `system/approved.md` تحت الفئة الصحيحة.

## 3. المهام الحالية والمستقبلية

*   **المهام العاجلة:**
    *   **فارس/ليلى:** مراجعة أمان لوحة الإدارة (`admin.html`) وتقديم توصيات.
    *   **فارس/ليلى:** إعداد ملف `README.md` شامل يشرح كيفية إعداد وتشغيل المشروع محلياً وعلى الخادم.
    *   **فارس/ليلى:** توفير الإعدادات والمتغيرات البيئية اللازمة لتشغيل خدمة الـ Backend (بالتشاور معك).
*   **المهام المخطط لها (حسب خطة التنفيذ):**
    *   البدء في تحسينات SEO الفنية (Schema Markup، Meta Tags، Content Depth).
    *   تطوير صفحات المدن (City Landing Pages).
    *   تطوير استراتيجية المحتوى للسوشيال ميديا.

## 4. سجل الفريق (Team Log)

يمكنك متابعة جميع الأنشطة اليومية للفريق في ملف `_manus_management/TEAM_LOG.md`.
