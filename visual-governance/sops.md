# 📋 مكتبة إجراءات الإنتاج البصري (SOPs)
> خطوات معيارية لكل نوع أصل بصري. كل SOP ينتهي ببوابة الامتثال الإلزامية.

## SOP-1 — صور المقالات (Article Images)
1. عمر يقرأ المقال + البريف + نظام D4L البصري.
2. يكتب برومبت من المكتبة (+ لاحقة الاحتشام) أو يلتقط/يختار صورة واقعية.
3. مسوّدات على نماذج منخفضة التكلفة → اختيار الأفضل.
4. صقل: تدرّج لوني دافئ متّسق، تكوين، عزل خلفية.
5. **بوابة الامتثال** → PASS فقط يُصدَّر WebP إلى `assets/images/`.
6. أرشفة المصدر + النهائي على Google Drive (فولدر عمر).

## SOP-2 — الصور البارزة (Featured Images)
- كـSOP-1 + نسبة 16:9 ثابتة، نقطة اهتمام قوية، مساحة للعنوان عند الحاجة.
- تمثّل روح المقال فوراً؛ تجتاز الامتثال قبل الربط.

## SOP-3 — جرافيك السوشيال (Social Graphics)
1. اشتقاق من المقال (كاروسيل/اقتباس/نصيحة).
2. قالب الهوية (ألوان، خط Almarai، الشعار).
3. نص قصير مقروء؛ تباين AA.
4. **بوابة الامتثال** → نشر عبر أداة الجدولة (بموافقة).

## SOP-4 — ثَمبنيلز يوتيوب (Thumbnails)
1. عمر يطبّق نظام الثَمبنيل (ملف 07): 3–5 كلمات، وجه محتشم عند الحاجة، شريط هوية.
2. اختبار القراءة على شاشة هاتف (< ثانية).
3. **بوابة الامتثال** (احتشام + clickbait = رفض) → 16:9 نهائي.

## SOP-5 — الشورتس/الريلز (Shorts/Reels)
1. فلاش يكتب سكربت + هوك 3 ثوانٍ من المقال.
2. 9:16، مساحة للكابشن، إيقاع هادئ-حيوي بالهوية.
3. **بوابة الامتثال** (كل فريم) → نشر بموافقة.

## SOP-6 — صور الـAI (AI Images)
1. برومبت من المكتبة + لاحقة الاحتشام + negative prompt.
2. مسوّدات على نماذج مجانية/لا محدودة؛ كريديت للنهائي فقط.
3. فحص اليدين/التشوّهات/النصوص الزائفة.
4. **بوابة الامتثال** → صقل بشري → WebP.

## SOP-7 — فيديو الـAI (AI Videos)
1. لوحة قصصية (storyboard) ملتزمة بالأنظمة.
2. توليد لقطات قصيرة → تجميع → تدرّج لوني بالهوية.
3. **بوابة الامتثال** (احتشام + دقة + إيقاع) → تصدير.

## SOP-8 — الاعتماد البصري النهائي (Final Visual Approval)
1. المدير البصري يجمع الأصل + سياقه.
2. تشغيل قائمة الامتثال الثمانية.
3. PASS → يُعتمد للنشر + يُسجَّل. FAIL → يُعاد بسبب واضح وإصلاح محدّد.
4. تسجيل القرار في سجلّ الامتثال (للتحسين المستمر).
