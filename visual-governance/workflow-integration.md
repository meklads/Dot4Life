# 🔄 دمج الحوكمة في سير العمل (Workflow Integration)
> بوابة الامتثال البصري **مرحلة إلزامية** بين الإنتاج البصري والاعتماد النهائي. لا يمكن تخطّيها.

## سير العمل المعدّل
```
اختيار الموضوع
   ↓
كتابة المحتوى (موني)
   ↓
المراجعة التحريرية (عامر)
   ↓
الإنتاج البصري (عمر / فلاش — حسب SOP)
   ↓
🚦 مراجعة الامتثال البصري (المدير البصري — 8 محاور)   ← بوابة إلزامية
   ├── FAIL → يُعاد للإنتاج بسبب + إصلاح محدّد
   └── PASS ↓
الاعتماد النهائي (عامر)
   ↓
النشر + الفهرسة
```

## القواعد الحاكمة
- **لا نشر دون PASS بصري.** البوابة لا تُتخطّى ولو ضاق الوقت.
- المقال بلا صورة رئيسية معتمدة = لا يُنشر.
- كل أصل مرفوض يُسجَّل في سجلّ الامتثال (سبب + إصلاح).
- تكرار نفس الرفض → عامر يشدّد النظام البصري المعني.

## نقاط البوابة (Approval Gates)
| البوابة | المالك | المعيار |
|--------|--------|---------|
| تحريرية | عامر | content-standards.md |
| **بصرية** | **المدير البصري** | **compliance.md (8/8)** |
| نهائية | عامر | الاثنتان مرّتا |

## التكامل مع البورد
- كل بطاقة محتوى تحمل حقل **visual_status**: `pending / pass / fail`.
- لا تنتقل البطاقة إلى «منشور» إلا و visual_status = pass.
