# 💗 D4L — نظام الاتجاه العاطفي
> كل صورة وفيديو يحمل شحنة عاطفية. نختارها بوعي. D4L تبني بالأمل لا بالخوف.

## المشاعر المستهدفة (نُنتجها)
| الشعور | كيف نُظهره بصرياً |
|--------|--------------------|
| **الأمل** | ضوء صاعد، آفاق مفتوحة، بداية/نمو (نبتة، طفل، فجر) |
| **الحكمة** | كبار سن، كتب، تأمّل هادئ، توقير |
| **التأمّل** | لحظة سكون، نظرة للأفق، مساحة سلبية |
| **الرعاية** | أيدٍ تساعد، إنصات، حضن عائلي محتشم |
| **الاكتشاف** | فضول صادق، انفتاح، رحلة، سؤال |
| **التحوّل الإيجابي** | قبل/بعد لطيف، نمو، إنجاز هادئ |

## المشاعر الممنوعة (نتجنّبها تماماً)
- **الصدمة:** صور مفزعة، انفعالات حادة، مفاجآت سلبية.
- **التخويف:** استغلال القلق (مرض مرعب، تهديد، كارثة) للضغط.
- **الإثارة الرخيصة (Sensationalism):** مبالغة، تهويل، عناوين فزع.
- **سيكولوجيا الـClickbait:** فضول كاذب، حجب خادع، وعد لا يُوفّى.

## قاعدة الترجمة
الموضوع الصعب (مرض، أزمة، خوف الأهل) يُعالَج **بزاوية الأمل والحلّ** لا بزاوية الترويع. نُظهر اليد الممدودة لا الهاوية.

> الاختبار النهائي: «بعد رؤية هذه الصورة، هل يشعر القارئ بطمأنينة وثقة، أم بقلق وضغط؟» لو الثاني → أعد التصميم.
