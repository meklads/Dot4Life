# 🏗️ مواصفة التنفيذ داخل المنصة (Platform Implementation Spec)
> أين يعيش النظام داخل لوحة الإدارة، وكيف يُبنى ليتوسّع. (التنفيذ المرحلي في اللوحة الحالية + خارطة للمنصة الكاملة.)

## 1) بنية التنقّل (Navigation)
قسم جديد أعلى الـsidebar: **🎨 الحوكمة البصرية**، بداخله تنقّل فرعي:
```
الحوكمة البصرية
├── الميثاق الحاكم
├── D4L ▸ (فلسفة · ألوان · تصوير · إضاءة · إنسان · احتشام · ثَمبنيل · عاطفي)
├── Graphics House
├── Human & Architecture
├── مكتبة البرومبتات
├── الإجراءات (SOPs)
├── الامتثال
└── قاعدة المعرفة
```

## 2) موضع القائمة (Menu Placement)
بعد «إدارة المحتوى» مباشرةً (سلطة عليا تسبق الأقسام التشغيلية).

## 3) صفحات الإدارة (Admin Pages)
- صفحة عرض كل وثيقة (markdown render — منفّذة في اللوحة).
- **(مستقبلاً)** صفحة «مراجعة امتثال» تفاعلية: بطاقة + 8 مفاتيح PASS/FAIL + حفظ في السجلّ.

## 4) جداول قاعدة البيانات (Database Tables) — للمنصة الكاملة
| الجدول | الحقول الأساسية |
|--------|------------------|
| `brands` | id, name, slug, positioning, language, sensitivity_level |
| `visual_systems` | id, brand_id, doc_key, content_md, version, updated_at |
| `visual_assets` | id, brand_id, type, url, article_id, status(pending/pass/fail) |
| `compliance_reviews` | id, asset_id, c1..c8 (bool), decision, reason, reviewer, created_at |
| `prompts` | id, category, brand_id, body, modesty_suffix |
| `audit_log` | id, entity, entity_id, action, actor, before, after, ts |
> في اللوحة الحالية (ستاتيك): البيانات في ملفات `visual-governance/*.md` + `tasks.json` (حقل visual_status). الجداول أعلاه خارطة عند الانتقال لمنصة ديناميكية.

## 5) الربط الداخلي (Internal Linking)
- كل وثيقة علامة تربط لـ: الميثاق + الامتثال + مكتبة البرومبتات.
- كل بطاقة محتوى تربط لأصلها البصري وحالة امتثاله.

## 6) قاعدة المعرفة (Knowledge Base Structure)
انظر `knowledge-base.md` — فهرس قابل للبحث لكل الوثائق.

## 7) الأذونات والأدوار (Permissions & Roles)
| الدور | القراءة | التعديل | الاعتماد البصري |
|------|---------|---------|------------------|
| جوست (مالك) | كل شيء | كل شيء | نعم (override) |
| عامر (محرّر/معماري) | كل شيء | الأنظمة + الأقسام | نعم |
| المدير البصري | كل شيء | السجلّ + البرومبتات | **نعم (البوابة)** |
| عمر/فلاش (منفّذون) | الأنظمة + SOPs | يرفعون أصولاً للمراجعة | لا |

## 8) بوابات الاعتماد + سجلّ التدقيق + التحكّم بالإصدارات
- **Approval Gates:** تحريرية → بصرية → نهائية (إلزامية بالترتيب).
- **Audit Logs:** كل قرار امتثال + كل تعديل نظام يُسجَّل (من/متى/ماذا).
- **Version Control:** الوثائق في git (تاريخ كامل، رجوع، فروق). كل تغيير = commit.

## 9) التنفيذ المرحلي
- **الآن (ستاتيك):** قسم اللوحة + عرض الوثائق + حقل visual_status في tasks.json.
- **لاحقاً (ديناميكي):** صفحة مراجعة تفاعلية + جداول DB + سجلّ تدقيق آلي.
