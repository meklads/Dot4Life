# 🏛️ نظام الحوكمة البصرية الرئيسي — Master Visual Governance System
> **المرجعية البصرية العليا** عبر كل العلامات والفرق وعمليات المحتوى وأنظمة الإنتاج بالذكاء الاصطناعي والنشر — الحالية والمستقبلية.
> هذا ليس دليل علامة. هذا **نظام تشغيلي طويل الأمد** يحكم كل صورة وفيديو يخرج باسم المؤسسة.

---

## مبدأ التوسّع (Scalability)
كل علامة = مجلد مستقل يرث من **الميثاق الحاكم** ويعرّف هويته الخاصة. إضافة علامة جديدة = نسخ `future-brand-template.md` → ملؤه → ربطه باللوحة. **لا إعادة تصميم للنظام إطلاقاً.**

## التسلسل الهرمي للسلطة
1. **الميثاق الحاكم** (00) — قواعد عابرة للعلامات لا تُخالَف.
2. **نظام العلامة** — يفصّل ضمن حدود الميثاق.
3. **الامتثال** (compliance) — البوابة التي لا يمر محتوى دونها.
4. **المدير البصري** (skill) — السلطة التنفيذية التي تطبّق كل ما سبق.

> **القاعدة الحاكمة:** لا تخرج صورة أو فيديو للعالم قبل أن يجتاز بوابة الامتثال البصري. لا استثناء.
