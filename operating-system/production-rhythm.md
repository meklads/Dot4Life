# 🎚️ إيقاع الإنتاج المحكوم — Governed Production Rhythm
> **سلطة الحَوكمة:** جوست فوّض عامر يضبط الكثافة. **القاعدة العليا: الجودة والاستمرارية قبل العدد — دائماً.** مقال واحد رائع آدمي بصورة ممتازة > أربعة عادية.

## القرار (يبدأ محافظاً، يرتفع بإثبات الجودة)
- **الانطلاق: مقالان عميقان/يوم** (عربي + إنجليزي + صورة ممتازة + مراجعة كاملة). إيقاع مستدام يحمي الجودة.
- **الرفع إلى ٣/يوم** فقط بعد **أسبوعين** جودة ثابتة بلا تنازل.
- **الخفض الفوري إلى ١/يوم** لو الجودة وقعت يوماً واحداً. لا نقاش.

## توزيع الأقسام (المرونة التي طلبها جوست)
- **الأقسام الـ٣ الأهم** (قصص مميزة · مقارنات وقرارات · السلام يبدأ من البيت): حضور **يومي بالتناوب** — كل قسم ~٤–٥ مرات/أسبوع ضمن إيقاع المقالين.
- **الأقسام الـ٤ الأخرى** (الصحة · رحلات الحياة الإسلاميات · العالم ينتظر أسرتك · العقار): **مرتان/أسبوع** لكل قسم، تُدمَج في حصّة اليوم على أيامها.
- **الإجمالي المستهدف:** ~١٢–١٤ مقالاً/أسبوع، كلها تعدّي البار.

## الجدول الأسبوعي (مبدئي — يضبطه عامر)
| اليوم | مقال ١ (أولوية) | مقال ٢ (أولوية/دوري) |
|------|------------------|-----------------------|
| السبت | قصص | الصحة |
| الأحد | مقارنات | رحلات الحياة (الإسلاميات) |
| الإثنين | السلام | العالم ينتظر أسرتك |
| الثلاثاء | قصص | العقار |
| الأربعاء | مقارنات | الصحة |
| الخميس | السلام | رحلات الحياة (الإسلاميات) |
| الجمعة | قصص | العالم ينتظر أسرتك / راحة |

## بوابة الجودة (لا تُتخطّى)
كل مقال: ١٣٠٠–١٨٠٠ كلمة · أسلوب آدمي شيّق · صفر شرطات · FAQ · مصادر محققة · **صورة رئيسية ممتازة محتشمة** · مراجعة عامر. **رسوب البار = لا نشر، ونخفّض العدد لا الجودة.**

## حوكمة عامر الأسبوعية
كل سبت: يراجع جودة الأسبوع، يقرّر رفع/خفض العدد، يحدّث هذا الملف. **الاستمرارية تُبنى بالإيقاع الثابت لا بالاندفاع.**
