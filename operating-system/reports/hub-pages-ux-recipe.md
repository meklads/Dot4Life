# وصفة UX/UI لصفحات الـ Hub — مرجع التطبيق

> **المصدر:** ما نجح فعلاً على `health.html` (2026-06-27) بعد مراجعة جوست.
> **القاعدة الحاكمة:** لا مساس بالهيدر (الناف + الهيرو + sub-nav) ولا الفوتر. التطوير في البودي فقط، عربي + إنجليزي.

## المبدأ: الأساسيات قبل التزيين

التزيين بلا أساس سليم = فشل. الترتيب الصحيح للعمل:
1. **التباين والخلفيات** (هل النص مقروء؟ هل الخلفية صحيحة؟)
2. **المحاذاة والإيقاع** (هل العناصر متحاذية؟ مسافات هادئة؟)
3. **الترتيب المنطقي** للأقسام
4. **اللمسات** (أيقونات، تدرّجات، حركات خفيفة)

## الأخطاء الجذرية المشتركة في صفحات الـ Hub (موروثة من القالب)

| العيب | السبب | الإصلاح |
|------|------|--------|
| نص أسود على خلفية داكنة في قسم الأدوات | `#page` بلا خلفية → يظهر لون البودي `--pillar-hero-0` الداكن خلف الأقسام غير الـ cream | `#page { background:#fff }` + `#page > .hl-section:not(--cream){ background:#fff }` (وداكن في dark mode) |
| مستطيل ملوّن بعرض الشاشة (شريط الدليل) | `.hl-guide-strip` full-bleed | تحويله إلى **بطاقة محتواة** داخل الحاوية بحدود وخلفية فاتحة ونص داكن |
| مستطيل داكن فوق الفوتر | `.site-footer { margin-top: clamp() }` يكشف خلفية البودي | `.site-footer { margin-top:0 }` |
| نص المقدمة لا يحاذي البطاقات | `max-width` على فقرة المقدمة | `max-width:none` فتمتد بعرض الحاوية |
| أسهم `→` نصيّة خام في مرجعية الموضوع | نص حرفي داخل `<li>` | تحييدها بـ `li{font-size:0}` + `a{font-size:..}` ثم `a::before{content:'→'}` (وللعربي `←`) |

## اللمسات الراقية (CSS فقط، مُثيمة عبر `--hh-*`)

- **eyebrow** → حبّة (pill) بخلفية مينت خفيفة وحدود.
- **h2** أكبر قليلاً + `letter-spacing` مضبوط.
- **الأركان (pillars)** بطاقات أعمق + شريط علوي عند المرور.
- **البطاقات المميزة** تدرّج فاخر + شريط علوي + ظل أعمق عند المرور.
- **بطاقات الأدوات** شريط علوي مُثيم + أيقونة ملوّنة بالثيم + رفع خفيف.
- **مرجعية الموضوع** شريط علوي + صفوف مفصولة بخط رفيع + أسهم CSS تتحرك عند المرور.
- احترام `prefers-reduced-motion`.

## الترتيب المنطقي المعتمد (canonical)

```
المقدمة (لماذا) → الأدوات → مرجعية الموضوع (خريطة) → الأدلة المنتقاة → شريط قراءة مميز → أحدث المقالات (feed ديناميكي أخيراً)
```

المنطق: فهم القيمة ← الأداة ← خريطة الموضوع ← محتوى منتقى ← توصية ← المتغيّر الحديث في النهاية.

## النطاق التقني

- كل صفحة hub لها `styles/pages/<page>-hub.css` بنفس أسماء التوكنات `--hh-*` (مُثيمة بألوان مختلفة) و`body.<page>-hub-page`.
- نُلحق بلوك التطوير في نهاية ملف الـ hub الخاص بكل صفحة (يَفوز لأنه الأخير) — لا نلمس `pillar-pages.css` المشترك ولا الهيدر/الفوتر.
- نرفع رقم نسخة CSS في الـ HTML لكسر الكاش.
