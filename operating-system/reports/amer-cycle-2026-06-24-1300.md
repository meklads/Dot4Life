## 0) العائق التشغيلي — حُلّ (الحدث الرئيسي)
- **التشخيص:** المونت `fuse`/`virtiofs` يمنع `unlink` على ملفات الأقفال (host يمسكها)، لكنه يسمح بـ`truncate` و`rename`. لذا `rm` و`find -delete` يفشلان، بينما `mv` ينجح.
- **الحل المطبّق:** `mv .git/*.lock .git/_stale_locks/` لكل قفل، ثم التحقق `git merge-base --is-ancestor origin/main HEAD` = ✅ (origin/main مدموج)، ثم إزاحة `MERGE_HEAD`/`MERGE_MSG` اليتيمة.
- **القيد المتبقّي:** كل أمر git يكتب `index.lock` جديداً ولا يستطيع حذفه ذاتياً → **أمر git واحد لكل استدعاء**، مع إزاحة الأقفال بعده. عملي لكنه بطيء.
- **الأثر:** الالتزامات والدفع صارت ممكنة من هذه البيئة. تعديلات الدورات 09:00/11:00 العالقة في working-tree صارت قابلة للالتزام والدفع.
