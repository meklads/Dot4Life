## 1) المشكلة الجذرية (Root Cause)
استغرق التحقّق من 6 صفحات **3 جولات REOPEN** لأن العيوب تُكتشف بعد البناء، لا تُمنَع أثناءه. الأصناف المتكرّرة:
- شرطة طويلة (—) يُدخلها البناء في حقول مولّدة (`alt`, meta) رغم أن المسوّدة صفر.
- فجوة EN: `FAQPage` JSON-LD والإخلاء المالي غابا عن النسخة الإنجليزية بينما العربية سليمة.
- `Title` > 60 حرفاً ومقطوع منتصف كلمة.

النتيجة: لو تكرّر النمط، فالعناصر العشرة الباقية تستهلك ~30 جولة. **الحل: بوابة بناء تمنع الإخراج إن سقط أي بند (fail-closed)، وتُشغَّل داخل `scripts/build-from-approved-draft.py` قبل كتابة الملف.**

## 2) المطلوب فوراً: حزمة بوابات البناء (Build Gate Suite)
دالّة واحدة `assert_build_gates(html, lang, section) -> raise BuildGateError` تُستدعى **قبل حفظ كل ملف**، وتفشل البناء (exit≠0) مع رسالة دقيقة بالبند والملف. البنود (مطابقة Definition of Done):

| البوابة | الفحص البرمجي | شرط النجاح |
|---------|----------------|------------|
| G1 em-dash | `html.count("—")` | = 0 (يشمل `alt`, `meta`, `title`, JSON-LD) |
| G2 word count | نثر مرئي (بعد تجريد script/style/tags) | ≥ 1200 (هدف 1300) |
| G3 Article schema | `"@type":"Article"` في `ld+json` | موجود وصحيح JSON |
| G4 FAQPage schema | `"@type":"FAQPage"` + عدد `Question` | موجود و Q ≥ 4 — **في كل اللغات** |
| G5 hero image | `<img ... src=*.webp ... alt="…">` + `og:image` | موجود + alt غير فارغ |
| G6 Title | `len(<title>)` بعد التركيب | ≤ 60 حرفاً، بلا قطع منتصف كلمة |
| G7 Meta | `len(meta description)` | ≤ 155 |
| G8 hreflang | وسوم `hreflang` | زوج ar/en موجود |
| G9 disclaimer | regex إخلاء (ع + إن) | موجود إن `section ∈ {health, finance, islamic, hajj, umrah, pregnancy, fitness, real-estate}` |
| G10 internal links | روابط داخلية وصفية | ≥ 3 |
| G11 JSON-LD valid | `json.loads` على كل بلوك `ld+json` | لا استثناء |

> القاعدة: **لا يُكتب ملف ما لم تمرّ G1–G11.** عند الفشل: اطبع `BUILD GATE FAIL [Gx] file=… detail=…` وأوقف العنصر (لا تُكمل الطابور بصمت).

## 3) إصلاح جذر فجوة EN (سبب رئيسي للجولات)
المعالجة الحالية تبني العربية كاملة وتترك الإنجليزية ناقصة. المطلوب:
1. **مسار بناء موحّد للّغتين**: نفس الدوال (`build_faq_jsonld`, `extract_disclaimer_html`, `build_title_seo`) تُطبَّق على ع و إن من نفس بنية المسوّدة، لا فرعان منفصلان.
2. **علامات المسوّدة موحّدة**: اعتمِد عناوين أقسام ثابتة يتعرّف عليها المحلّل في اللغتين (مثل `## FAQ` / `## Frequently Asked Questions` و سطر `Disclaimer:`/`إخلاء مسؤولية:`). وثّقها في `claude-chef-execution-plan.md` ليلتزم بها Hema.
3. **تأكيد تكافؤ (parity assert)**: بعد بناء الزوج، `assert parity(ar, en)` — نفس عدد بلوكات Schema، وجود FAQPage في الاثنين، ووجود الإخلاء في الاثنين إن كان القسم حسّاساً.

## 4) مصدر العنوان (G6) — منع القطع
لا تقصّ العنوان الكامل ميكانيكياً. اشتقّ `title_seo` قصيراً (≤ 47 حرفاً للنصّ) ثم أضف اللاحقة ` | DOTFORLIFE` ليبقى الإجمالي ≤ 60، وادفع `assert_title_gate()` ليرفض أي قطع منتصف كلمة (آخر محرف ليس جزءاً من كلمة مبتورة).
