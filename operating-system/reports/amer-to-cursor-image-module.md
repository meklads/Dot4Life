# 🖼️ طلب لـCursor — وحدة الصور (Image Module) يتولّاها عمر، يستهلكها Cursor
> من: عامر (QA Commander) — إلى: Cursor (Build Commander). التاريخ: 2026-06-22. أولوية: P0 (العائق الحاسم لبلوغ 60%).

## الفكرة (قرار جوست)
قسم مستقل لاختيار الصور حسب معاييرنا، **مالكه عمر (المصمم)**، و**Cursor يستهلكه** في المقالات. نفس مبدأ الحارات: عمر يختار/يجيز، Cursor يضع فقط.

## البنية المطلوبة (manifest-driven · fail-closed)
1. **مجلد صور معتمدة:** `assets/images/approved/` — لا يضع فيه إلا عمر بعد إجازة «المدير البصري» (احتشام/هوية/ألوان/جودة).
2. **ملف فهرس واحد:** `assets/images/image-manifest.json` يملؤه عمر، لكل مقال صف:
```json
{
  "article_slug": "investment-basics-beginners",
  "image": "assets/images/approved/hero-investment-basics-beginners.webp",
  "alt_ar": "نصّ بديل عربي وصفي بلا شرطة طويلة",
  "alt_en": "descriptive English alt, no em-dash",
  "visual_director": "approved",     // approved | rejected | pending
  "by": "عمر", "date": "2026-06-22"
}
```
3. **مستهلِك في البناء:** عند بناء/تحديث أي مقال، يقرأ السكربت الفهرس:
   - `visual_director == "approved"` → ضع الصورة + alt من الفهرس.
   - غير ذلك (pending/مفقود) → **لا تبنِ بصورة افتراضية**؛ علّم الصفحة `BLOCKED_IMAGE` واتركها حتى يجيز عمر. (fail-closed)
4. **تصليب البوابة G5:** بدل قبول أي `.webp`/og:image، اجعل G5 يتطلّب أن تكون الصورة **من الفهرس وحالتها approved**. الصور الافتراضية الحالية (~40–62 من og:image) = placeholder، تُستبدل تدريجياً بصور عمر المعتمدة.

## تقسيم الحارات (لا تداخل)
| العمل | المالك |
|------|--------|
| إنتاج/اختيار الصورة + الـalt + إجازة بصرية + ملء `image-manifest.json` | **عمر** |
| بناء مستهلِك الفهرس + تصليب G5 + وضع الصور في HTML | **Cursor** |
| التحقّق أن الصفحة المكتملة فيها صورة معتمدة (BUILD VERIFY) | **عامر** |
| النصّ (لا علاقة له بالصور) | Hema |

## لماذا fail-closed مهم
يمنع تكرار مشكلتنا: صفحات تُبنى بصورة عامة/ناقصة فتسقط لاحقاً أو تضرّ الهوية. لا صورة معتمدة = لا نشر، بدل «نضع أي صورة ونصلح لاحقاً».

## المطلوب منك (Cursor)
1. ابنِ قارئ `image-manifest.json` + مستهلكه في `build-from-approved-draft.py` + سكربت blog.
2. صلّب G5 ليرفض غير المعتمد من الفهرس.
3. جهّز الفهرس فارغاً + مجلد `approved/` ليبدأ عمر ملأه.
4. لا تستبدل الصور الافتراضية الحالية إلا بما يعتمده عمر في الفهرس (تدريجي، بلا كسر للصفحات الحيّة).

> رأيي: الفكرة صحيحة، وقيمتها كلها في كونها **مدفوعة بفهرس معتمد وfail-closed**. عند الجاهزية، أعطي عمر تعليمات دفعة الإنتاج (المواصفات + قائمة المقالات المنتظرة للصورة).
> ردّك المتوقّع: ✅/❌ + ETA بناء المستهلِك، في تقرير 👑 جوست.
