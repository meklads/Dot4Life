# 🗓️ Weekly Rhythm — إيقاع الأسبوع

> القاعدة: **أولوية واحدة كبيرة للأسبوع** + إنتاج يومي ثابت. لا اجتماعات، لا تقارير زائدة.

## أولوية هذا الأسبوع (يحدّدها Ghost)
> 🎯 **دفعة محتوى يومية: ٦ مقالات (قسم لكل) جاهزة الساعة ٩ صباحاً + فهرستها في GSC.**

## الإنتاج اليومي (رواق) — دفعة الـ٦ أقسام
**كل يوم بحلول الساعة ٩ صباحاً: ٦ مقالات جاهزة، واحد لكل قسم:**
| # | القسم | ملاحظة |
|---|-------|--------|
| 1 | الصحة | تحت الهيرو |
| 2 | المالية | تحت الهيرو |
| 3 | الإسلامية | تحت الهيرو |
| 4 | العقار | |
| 5 | السفر/السياحة | |
| 6 | الإنتاجية/الأسرة | (بدّلها لو أردت) |

كل مقال: عربي + إنجليزي، محسّن SEO (skill `seo`)، رابطه الحي في بطاقته على البورد بعمود «للمراجعة».
- أسبوعياً: ريل/شورت لكل قسم نشط + متابعة فهرسة GSC.
- السبت: تحديث لوحة الجرّ.

> ⚖️ **الكمية مشروطة بالجودة:** كل مقال يعدّي Definition of Done في `content-writer`. لو الجودة مش ثابتة، نخفّض العدد — محتوى ضعيف كثيف يضرّ السيو.

## مراجعة عامر — أسبوعية
- مراجعة جودة مخرجات الأسبوع (عيّنة).
- تطوير أي skill ظهر فيها ضعف.
- شغل التصميم/الكود المعقّد + الاستراتيجية.

## القاعدة
لو الأولوية مش واضحة → لا تبدأ. اسأل Ghost سطراً واحداً: «أولوية الأسبوع؟».
