## المسار 1 — تواصل الفريق (محلي فقط · فوري · بلا Git)
- الملفات: `TEAM-BUS.md` · `inbox/*.md` · `AMER-ORDERS-ACTIVE.md` · تقارير القرارات.
- كل الوكلاء (عامر/هيما/كورسر) **يشتركون في نفس الفولدر على جهاز جوست** → الكتابة المحلية يراها الجميع **فوراً**.
- **لا يُدفع لكل رسالة.** لا قفل، لا تصادم، لا نقل من جوست.

## المسار 2 — نشر الموقع (Git · دفعة واحدة كل 30د)
- المحتوى الحيّ فقط: مقالات HTML · صور `assets/images/approved/` · الفهرس · sitemap.
- **المنسّق يجمّع كل التغييرات ويدفعها مرة كل دورة** (`git pull -X ours` ثم `push`) — ناشر واحد.
- ملفات القمامة (`__pycache__`, `*.log`) مُتجاهَلة.

## القاعدة السلوكية (لعامر والوكلاء)
1. **التواصل/القرارات → اكتب محلياً فقط.** لا تدفع لـ GitHub لكل رسالة.
2. **المحتوى الجاهز للنشر → يلتقطه المنسّق ويدفعه دفعةً.**
3. **عامر لا يكابر على Git في الجلسات التفاعلية** — يكتب القرار محلياً (يراه الفريق فوراً)، والدفع للمنسّق.
4. النتيجة: صفر تعطّل بالقفل · صفر نقل يدوي من جوست.
