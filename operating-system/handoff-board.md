## كيف تشتغل (3 دقائق)

1. **افتح هذا الملف** — شوف عمود «عند جوست» أو عمود العضو الحالي.
2. **اسحب mentally** — انقل الصف للعمود التالي (أو قل لـ Cursor: «انقل H-07 لكلود»).
3. **انسخ «أمر جوست»** — الصقه للعضو في الشات (سطر واحد).
4. لما يقول **«تم»** — انقل للعمود التالي + أمر العضو الجديد.
5. **Cursor / Autopilot** يبني تلقائياً بعد `approved` — **ما تحتاج موافقة بناء**.

### مسار كل بطاقة صورة (دائرة واحدة)

```
جوست → عمر (برومبت) → كلود (توليد) → عمر (approved+WebP) → Cursor (بناء) → عامر (تحقق) → ✅
```
