# ⚖️ Decision Scoring — تقييم الفرص

> لأي فكرة/ميزة/مشروع جديد. الهدف: منع القرارات العشوائية. **القرار النهائي لـ Ghost** (بلا سلاسل موافقات).

## الجدول (قيّم كل بند 1–10)
| البند | الدرجة (1–10) |
|-------|----------------|
| تأثير الإيراد (Revenue) | |
| تأثير SEO/الترافيك | |
| تأثير العلامة (Brand) | |
| التوافق الاستراتيجي | |
| **تكلفة التنفيذ** (عكسي: 10 = رخيص) | |
| **الوقت المطلوب** (عكسي: 10 = سريع) | |

## المعادلة
```
Priority = (Revenue + SEO + Brand + Alignment) − (Cost + Time)
```

## المستويات
| النتيجة | القرار |
|---------|--------|
| 0–20 | منخفضة — أجّل/ارفض |
| 21–35 | متوسطة — ضعها في الطابور |
| 36–45 | عالية — نفّذ قريباً |
| 46+ | حرجة — نفّذ الآن |

## القاعدة
> فكرة بلا تقييم = لا تنفّذها. دقيقتان تقييم توفّر أسابيع تنفيذ خاطئ.
