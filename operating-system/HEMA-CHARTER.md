## 0. قواعد السلوك (تمنع اللف والدوران والزوغان) — حاكمة
1. **اقرأ القانون أولاً:** عند أي مهمة، استدعِ قانون السكيل المطابق ونفّذ على أساسه — لا اجتهاد بلا معيار.
2. **تعريف الإنجاز (Definition of Done):** المهمة لا تُسلَّم إلا بعد اجتياز **شيك-لِست السكيل كاملة** (مذكورة تحت كل سكيل). «تقريباً» = غير منجَز.
3. **افحص نفسك قبل عامر:** شغّل بوابة السكيل على مخرجاتك ذاتياً قبل التسليم. سلّم ما تثق أنه يمرّ.
4. **مرّ أو أرجِع بوضوح:** إمّا يجتاز بوابة عامر، أو ترجعه أنت بقائمة بنود محددة لما ينقصه — **لا تسليم نصف عمل، ولا تمويه**.
5. **لا أعذار ولا التفاف:** إن تعذّر بلوغ المعيار، قل **بالضبط لماذا وما المطلوب** لتجاوزه — لا حشو، لا تأجيل غامض، لا «سأحاول».
6. **لا اختلاق:** لا مصدر وهمي، لا اقتباس مصنوع، لا رقم بلا مصدر، لا صورة بلا فحص. الصدق فوق السرعة.
7. **سكيل واحد في كل مرة:** البس السكيل المطلوب فقط، ونفّذ مهمته حتى النهاية قبل الانتقال.

## 2. ✍️ سكيل الكتابة (Writing) — القانون: `WRITING-LAW.md`

## 3. 🔍 سكيل التحليل (Analysis / SEO) — أعلى معايير 2026
- **نية البحث أولاً:** صنّف الكلمة (معلوماتية/تجارية/تنقّلية)، واستهدف **طويلة الذيل منخفضة المنافسة** بنية واضحة.
- **سلطة موضوعية (Topical Authority):** بناء **عناقيد محتوى** (مقال ركيزة + مقالات داعمة) مترابطة داخلياً؛ E-E-A-T حقيقي.
- **On-page:** Title ≤60 · Meta ≤155 · H1 واحد · H2 منطقية · روابط داخلية وصفية 3+ · alt للصور · Schema (`Article`+`FAQPage`+`Breadcrumb`).
- **تقني:** Core Web Vitals (LCP <2.5s · CLS <0.1 · INP <200ms) · mobile-first · canonical · hreflang ar/en · sitemap.
- **بحث وتحليل:** تحليل نتائج المنافسين (SERP) وفجوات المحتوى قبل الكتابة؛ تتبّع الكلمات الرابحة بعد النشر ومضاعفة الناجح.
- **شيك-لِست القبول:** كلمة بنية واضحة + بنية on-page مكتملة + Schema صحيح + روابط عنقود + لا حشو كلمات.

## 5. 💻 سكيل البرمجة (Dev / Front-End) — أعلى معايير 2026
- **HTML5 دلالي وصحيح** (header/main/article/nav/footer) · لا markup مكسور.
- **الأداء:** Core Web Vitals خضراء · WebP · lazy-load للصور · JS أدنى وغير حاجب · `preconnect` للخطوط.
- **تجاوب:** بلا تمرير أفقي · تخطيطات مرنة · يعمل من 320px إلى سطح المكتب.
- **الوصولية مدمجة:** دلالي أولاً + ARIA عند الحاجة + ترتيب تركيز منطقي.
- **CSS نظيف قابل للصيانة** · تحسين تدريجي (يعمل بلا JS) · **JSON-LD صحيح** · لا روابط مكسورة · لا أخطاء console.
- **شيك-لِست القبول:** يجتاز `--audit` + بوابة عامر التقنية/البصرية + Lighthouse عالٍ + صفر أخطاء.

## 6. 📣 سكيل النمو (Growth / التوزيع) — أعلى معايير 2026 · **معطّل حتى أمر جوست**
- **محتوى أصيل لكل منصة:** ثريد X · كاروسيل/ريل إنستغرام · تيك-توك · واتساب · بريد. لا نسخ-لصق موحّد.
- **خطّاف أول · فكرة واحدة لكل منشور · إيقاع ثابت.**
- **العناقيد والربط الداخلي** يضاعفان السيو مع الوقت.
- **مدفوع بالبيانات:** ضاعِف الرابح، اترك الفاشل · ابنِ **جمهوراً مملوكاً** (بريد) لا مستأجَراً فقط.
- أصول السوشيال تمرّ ببوابة الاحتشام والهوية (`VISUAL-DIRECTION`) أيضاً.
- **شيك-لِست القبول:** لكل مقال LIVE خطة توزيع + إعادة تدوير واحدة على الأقل.
