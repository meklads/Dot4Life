# ✅ خطة الغد — نقاط محدّدة للمراجعة

## 👑 جوست (أنت) — مهام يدوية تفتح الطريق (الأهم)
- [ ] **شغّل «Run now» مرة واحدة** على كل مهمة مجدولة (بريف ٨م، مراجعة ٩ص، مراقبة كل ساعتين، تحليلات السبت) — لاعتماد صلاحياتها فلا تتوقف لاحقاً.
- [ ] **اربط Ahrefs** (الرابط المُرسَل) — للكلمات الدلالية بـ KD حقيقي.
- [ ] **شغّل رواق** وقُل له: «اعمل git pull، افحص البورد، نفّذ أمر تصميم عمر + ابدأ دفعة المحتوى من content-plan». *(رواق ليس مستمراً — يحتاج تشغيلاً.)*
- [ ] **وضّح لي: عمر جلسة منفصلة أم skill يستدعيه رواق؟** (لأضبط توجيه الأوامر وأحدّث TEAM-CONTEXT.)
- [ ] **ثبّت القاعدة:** عامر يملك البنية، رواق إنتاج فقط (ممنوع restructure) — لإيقاف فوضى git.
- [ ] (اختياري) اربط **Search Console + GA4** للتحليلات التلقائية، أو جهّز تصديراً.

## 🏗️ عامر (أنا)
- [ ] أقرأ الميثاق + المعايير + سجلّ الجودة (طقسي اليومي).
- [ ] **بريف الغد:** رادار أخبار/ترندات/طلب → عناوين + كلمات دلالية قوية (long-tail, KD≤20) لكل قسم → `content-plan.md`.
- [ ] **مراجعة ٩ص:** أراجع، **أحرّر بنفسي ما يحتاج صقلاً**، أعتمد الممتاز فقط، أنشر، أرفع لك تقريراً مقالاً مقالاً.
- [ ] أسجّل دروس الجودة وأشدّد المعايير.

## ⚡ رواق + الفريق
- [ ] **رواق:** git pull → يفحص البورد → ينفّذ أوامر الطوارئ + دفعة المحتوى (متأنّي، قسم قسم، 30د بين الأقسام).
- [ ] **موني (محتوى):** مقالات الأقسام من البريف فقط — 1300+ كلمة، عميقة، آدمية، عربي + إنجليزي. ثم تتوقف للمراجعة.
- [ ] **عمر (تصميم):** ① الأمر الطارئ: تطوير تصميم أقسام الهوم بيج. ② صورة رئيسية لكل مقال → `assets/images/`.
- [ ] **ميدو (SEO):** كلمات + on-page + Schema + روابط داخلية لكل مقال. ومتابعة الفهرسة في GSC.
- [ ] **القاعدة:** الكل يضع النتيجة في «للمراجعة» على البورد ولا ينشر — ينتظر اعتماد عامر.

## 🎯 هدف الغد
دفعة محتوى **عميقة** أولى تعدّي المعايير + تصميم الهوم بيج جاهز للمراجعة — **الجودة قبل الكمية.**
