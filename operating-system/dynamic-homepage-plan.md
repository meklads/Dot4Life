# 🏠 خطة الهوم بيج الديناميكي — الصح هذه المرة (#2)
> **المبدأ الحاكم:** لا نحذف التصميم الثري — **نحقنه بالبيانات.** التصميم الثابت يبقى **fallback**، وJS يستبدل محتواه بأحدث المقالات. **الهوم لا يفرغ ولا يُكسر أبداً.**

## القاعدة الذهبية (تمنع كارثة الحذف اللي حصلت)
- **ممنوع حذف المحتوى الثابت.** يبقى كـ**fallback**: لو JS فشل أو `articles.json` مش متاح → الثابت يظهر.
- JS **يحسّن (hydrate/enhance)** لا يبني من صفر: يملأ حاويات التصميم الموجودة بأحدث المقالات.

## الخطوات (لكل قسم ثري في الأعلى)
1. **لا تغيّر التخطيط ولا الـCSS.** نفس الكروت، نفس الأحجام، نفس السايدبار. (الشكل القديم هو المرجع.)
2. علّم حاويات كل قسم: `data-feed-section="featured-stories | comparisons | peace-capsules"` + عدد البطاقات.
3. `feed.js` عند التحميل: لكل حاوية → يجيب **أحدث N مقالات** لقسمها من `articles.json` → **يستبدل محتوى البطاقات الموجودة** (العنوان/الصورة/الوصف/الرابط) **محافظاً على نفس الـmarkup والستايل**.
4. **Fallback:** فشل `articles.json` → الحاوية تحتفظ بمحتواها الثابت. **لا فراغ.**
5. الصور من articles.json: **محتشمة** (أشياء/مشاهد بلا أشخاص مكشوفين)، `object-fit:cover` + ارتفاع ثابت (لا عملقة).

## الترتيب النهائي للهوم (مثبّت)
الهيرو → الأقسام الثرية الديناميكية (قصص/مقارنات/سلام...) → باقي الأقسام → **«جديد المقالات» (feed عام)** → **فورم التسجيل (آخر شيء قبل الفوتر)** → الفوتر.

## الاختبار قبل أي «تم» (على الـURL الحيّ)
- JS شغّال: الأقسام تعرض **أحدث المقالات الفعلية** بصورها المحتشمة المحجّمة.
- JS معطّل (محاكاة): الأقسام تعرض المحتوى الثابت (fallback) — **لا فراغ ولا كسر.**
- اختبار على الموقع الحيّ، **لا Puppeteer محلي وحده.**

## 🎯 سبيك الخانات الدقيق (slots) — كيف يتحدّث كل قسم
**الترتيب:** feed.js يرتّب مقالات كل قسم بحقل `date` تنازلياً (الأحدث أولاً) ويملأ الخانات.

### القسم 1 (الأبرز) — كارت كبير + قائمة
- `data-feed-section="featured-stories" data-role="hero"` → يُملأ بالمقال **[0]** (الأحدث): صورة كبيرة + عنوان + وصف + رابط.
- `data-feed-section="featured-stories" data-role="list" data-count="5"` → يُملأ بالمقالات **[1..5]** (عناوين).

### القسمان 2 و3 — شبكة 3 كروت
- `data-feed-section="comparisons" data-count="3"` → أحدث 3.
- `data-feed-section="peace-capsules" data-count="3"` → أحدث 3.

### القواعد
- **استبدال المحتوى فقط** (عنوان/صورة/وصف/رابط) داخل نفس الـmarkup/الستايل. لا تغيير تخطيط.
- **fallback:** محتوى ثابت افتراضي داخل كل خانة في الـHTML — لو articles.json فشل، يظهر الثابت (لا فراغ).
- **الصور:** من articles.json، محتشمة، `object-fit:cover` بارتفاع ثابت (لا عملقة).
- **التواريخ:** لازم تكون صحيحة في articles.json حتى يصحّ الترتيب بالأحدث.

## أمر عمر
نفّذ هذا السبيك على الأقسام الثلاثة العلوية. اختبر على الـURL الحيّ (JS شغّال = الأحدث يظهر · JS معطّل = الثابت يظهر، لا كسر). أبلغ عامر برابط حيّ قبل «تم».
