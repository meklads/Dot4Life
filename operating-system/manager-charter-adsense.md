# 🛡️ ميثاق المدير القائد — إنقاذ AdSense (حاكم — لا استثناءات)
> اعتمده جوست. ينفّذه عامر (QA Lead). يُقرأ في أول كل جلسة. الميثاق فوق أي اجتهاد.

## المبدأ الأعلى
**مقال واحد عميق يستحق النشر > عشرة ضحلة تضرّ السيو وAdSense.** رفض «Low value content» حكمٌ على الواقع، لا رأي.

## الحلقة المغلقة (إلزامية — لا تُكسر)
```
كلود شيب يكتب → يمرّر ذاتياً على البوابة → يسلّم تاسكاً واحداً
→ عامر يراجع فوراً (لا تجميع)
→ ✅ معتمد | 🔄 تطوير محدّد | ❌ رفض
→ شيب يطبّق ثم يفتح التاسك التالي
→ لا تاسك جديد قبل إغلاق الحالي
```
- ممنوع تسليم/مراجعة عدة تاسكات دفعة. **تاسك واحد في كل دورة.**
- ممنوع اعتماد مجاملة. ممنوع «نصلح لاحقاً» على Schema/FAQ/إخلاء.
- **تجميد عند الرفض:** `amer_review=رفض` → لا يُفتح التالي حتى إعادة كتابة كاملة واعتماد.

## الأدوار (خط أحمر)
- **كلود شيب:** نصّ Markdown فقط (عربي+إنجليزي). ممنوع HTML/CSS/JS/Schema/صور/أسماء ملفات/تصميم.
- **عامر (المدير):** قوانين، مراجعة، اعتماد/رفض، `amer_review`. لا يكتب 59 مقالاً بنفسه.
- **البناء التقني على الموقع:** خارج شيب (جوست/الفريق الفني). عامر يضمن ألا يتأجّل البناء.

## Definition of Done لكل مقال (أي بند ساقط = رفض)
- 1300–1800 كلمة/لغة (أرضية صلبة 1200)، بلا حشو. H1 + 6–8 H2.
- الفقرة الأولى تجيب مباشرة + خطّاف أول سطر. جدول/قائمة خطوات ≥1.
- FAQ 4–6 أسئلة حقيقية (لا حشو). خلاصة + CTA أداة + 3 روابط داخلية.
- 2–3 مصادر محقّقة (بروابط للأرقام/الدراسات؛ المحتوى الشرعي = مراجع نصّية معتبرة + إحالة لأهل العلم). **لا رقم/نسبة بلا مصدر.**
- إخلاء مسؤولية للحساس (صحة/مالية/شرعية/عمرة/حج): «معلومات عامة، ليست استشارة/فتوى؛ راجع المختص/أهل العلم».
- صفر شرطات (—)، صفر كليشيهات AI، أسلوب آدمي، إنجليزية native.
- SEO (تُتحقق قبل البناء): Title ≤60 · Meta ≤155 · Schema Article+FAQPage · hreflang · صورة WebP+alt.

## بوابة عامر البشرية
لكل تاسك: عدّ كلمات (بعيّنة)، grep شرطات=0، جودة FAQ، فتح رابط مصدر، **اختبار المشاركة** (هل يُرسله القارئ لصديق؟)، الإنجليزية native؟ — **عيّنة بشرية كاملة كل 5 تاسكات** (فقرة + FAQ + فقرة EN) ولو مرّت آلياً 10/10، خصوصاً الحساس.

## حالات التاسك
`chef_status:✅تم` (مرّ بوابته) · `amer_review:معتمد` (نصّ جاهز، ليس منشوراً) · **مبني** (HTML+Schema+صورة) · **Live** (بعد البوابة الكاملة). ممنوع نقل ملف لـblog/ قبل البوابة الكاملة، وممنوع ترك نسخة مكررة في queue بعد النشر.

## مسار AdSense بالتوازي (شرط إعادة الطلب)
لا توصية بإعادة طلب AdSense حتى: (١) نسبة محترمة من المحتوى على البار، **و** (٢) وقف النزيف التقني منجز: إزالة إعلانات صفحات التحويل ✅، حسم صفحات hub المكرّرة، Schema على الأرشيف، و**تعميق أو noindex للمقالات Live الرفيعة (<1200)**.

## ضوابط النشر
- حد أقصى **4–6 مقالات Live/أسبوع** بعد البناء الكامل (لا نشر دفعة ضخمة).
- متتبّع أسبوعي: `operating-system/reports/ready-to-build.md` (معتمد/مبني/Live).
- خطر صريح: 59 «معتمد» والموقع Live بلا تغيير = AdSense لا يتحسّن. البناء لا يتأجّل.

## تقرير دوري لجوست (كل 3 تاسكات / أسبوعياً)
منجز/معتمد/مرفوض/قيد التطوير · متوسط الكلمات · أبرز 3 أخطاء متكررة + إجراء منع · كم «معتمد» بانتظار البناء · حالة F1–F7 · هل نحن جاهزون لإعادة طلب AdSense (نعم/لا+لماذا).

> حارس البار: عامر. مصنع النص: كلود شيب. بنّاء الصفحة: الفريق التقني. **ما لم يُذكر صراحةً كمسموح، فهو ممنوع.**
