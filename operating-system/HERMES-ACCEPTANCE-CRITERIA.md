## 0.5 أولوية كل تشغيلة — حلقة التصحيح الذاتي (إلزامي قبل أي محتوى جديد)
**أول ما يبدأ Hermes أي تشغيلة، وقبل كتابة أي مقال جديد:**
1. اقرأ `TEAM-BUS.md` + `quality-log.md` والتقط كل ملف عزلته بوابة CI (`noindex,nofollow`) أو رفضه عامر.
2. **أصلِح المعزول أولاً** حتى يعدّي `amer_gate.py` كاملاً (بما فيه الفحص البنيوي بند 15)، ثم أزل وسم `noindex` وأعد تسليمه للبوابة.
3. **لا تكتب مقالاً جديداً وفي الطابور ملف معزول لم يُصلَح.** الإصلاح قبل الإنتاج — لأن الجودة قبل الكمية.
> الهدف: الحلقة تُصحّح نفسها بين بوابة CI (المجانية) وHermes، **دون انتظار جلسة عامر المدفوعة**. عامر = تدقيق دوري واستراتيجي، لا مُصحّح كل ملف.

## 1. خط الإنتاج الإلزامي (لا تجاوز)
```
Hermes·كتابة (مسودة) → [بوابة Hermes الذاتية: amer_gate.py] → Hermes·بناء (HTML)
   → عمود "عامر" في handoff-tickets (qa_status=pending)
   → فحص عامر المستقل (نص + سكيما + صورة + صفحة) → approved | rejected
   → approved فقط → col:done (LIVE) + sitemap + site-sections.json
```
**ممنوع نهائياً:** أي بطاقة `*-BUILD` تُنقَل إلى `col:done` مباشرة من Hermes·بناء. هذا خرق وقع 8 مرات متتالية في 2026-06-30 (D25→D32) ويُصحَّح آلياً بإرجاعها لـ`hermes_write` بصرف النظر عن جاهزية النص.
